# รูปแบบไฟล์สคริปต์คลิป (อ้างอิง)

ไฟล์นี้กำหนดหน้าตาของสคริปต์ทุกคลิป ใช้คู่กับส่วน A ใน SKILL.md
เขียนเป็น Markdown ตามแม่แบบด้านล่างทุกครั้ง ห้ามเพิ่มหรือสลับหัวข้อระดับ ##
ถ้าทำไฟล์ Word ให้แปลงจากโครงนี้ตามสเปกในส่วน D

## กฎการจัดรูปแบบ

### ระดับหัวข้อ
- `#` มีบรรทัดเดียว คือชื่อไฟล์สคริปต์ รูปแบบ: `สคริปต์เสียงพูด คลิป X.Y [ชื่อคลิป]`
- `##` ใช้เป็นหัวส่วนหลัก มี 7 ส่วนตามลำดับนี้เท่านั้น
  1. ข้อมูลคลิป
  2. Cold Open และวางกรอบ (00:00 - mm:ss)
  3. ส่วนที่ 1 [ชื่อส่วน] (mm:ss - mm:ss)
  4. ส่วนที่ 2, 3 (และ 4 ถ้ามี) ใช้รูปแบบเดียวกัน
  5. สรุป งานมอบหมาย และ Cliffhanger (mm:ss - mm:ss)
  6. ตารางภาพประกอบ (Visual Timeline)
  7. หมายเหตุผู้บรรยาย
- `###` ใช้เฉพาะในหมายเหตุผู้บรรยาย มี 3 หัวข้อ: จุดที่ต้องระวังตอนอ่าน / จุดเชื่อมกับคลิปอื่น / จุดที่ต้องตรวจก่อนอัด
- ช่วงเวลาในหัวข้อเขียนแบบ `(01:30 - 04:30)` เว้นวรรคทั้งสองข้างของขีด ใช้ขีดสั้น (-) เท่านั้น

### บรรทัดใต้ชื่อเรื่อง
บรรทัดที่สองเป็น `วันที่ (YYYY-MM-DD) · ชื่อผู้สอน`

### ป้ายเวลาย่อย
ภายในส่วน Cold Open และส่วนสรุป ให้แบ่งช่วงด้วยบรรทัดตัวหนาของตัวเอง
`**[00:00 - 00:40] Cold Open**`
`**[00:40 - 01:30] วางกรอบ**`
`**[13:00 - 13:40] สรุป**`
`**[13:40 - 14:20] งานมอบหมาย**`
`**[14:20 - 15:00] Cliffhanger**`
ส่วนเนื้อหาที่ 1 ถึง 4 ไม่ต้องมีป้ายเวลาย่อย

### บทอ่าน
- หนึ่งย่อหน้าต่อหนึ่งความคิด ไม่เกินราว 4 ประโยค
- `//` อยู่กลางย่อหน้า เป็นตัวหนา มีเว้นวรรคหน้าและหลัง: `ประโยค **//** ประโยค`
- `///` วางเป็นย่อหน้าเดี่ยว: `**///**` ใช้คั่นระหว่างก้อนความคิดใหญ่
  หรือใช้กลางย่อหน้าได้เมื่อรอให้ผู้ฟังคิด
- คำที่ต้องเน้นเสียงเป็นตัวหนา ไม่เกิน 1 ถึง 2 จุดต่อย่อหน้า
- หัวข้อย่อยในเนื้อหา (เช่น กฎข้อที่หนึ่ง บ่อที่หนึ่ง) เปิดย่อหน้าด้วยตัวหนา แล้วต่อ `**//**`
  `**ข้อที่หนึ่ง จดไว้ที่เดียว** **//** คำอธิบาย...`
- ตัวอย่างประกอบขึ้นย่อหน้าใหม่ด้วยคำว่า `ตัวอย่างโน้ต "..."` หรือ `ตัวอย่าง "..."`
- ทางเลือกสำหรับผู้เริ่มต้น ขึ้นย่อหน้าใหม่ด้วยคำถาม เช่น `แล้วถ้าคุณยังไม่มี...ล่ะ **//**`
- ส่วนที่ผู้สอนเติมเอง ใช้ `[ผู้สอนยกตัวอย่าง...]` ในบรรทัด
- รายการขั้นตอนใช้ลำดับเลข `1.` และให้คำแรกของแต่ละข้อเป็นตัวหนา
- ตารางในบทอ่านใช้ได้เมื่อสิ่งที่พูดเป็นตารางจริง เช่น ตารางวัน มีแถวหัวตาราง

### ข้อมูลคลิป
ย่อหน้าเดียว ตามด้วยรายการสัญลักษณ์
```
คลิป X.Y ยาว mm:ss นาที เป้าหมายราว N คำ (จับเวลาอ่านจริงก่อนอัด) อยู่ใน [หน่วยใหญ่] N [หน่วยย่อย] N ([ชื่อหน่วยย่อย]) และวัด [CLO/ELO]
```
รายการสัญลักษณ์
```
- **//** เว้น 1 วินาที
- **///** เว้น 2 วินาที
- **ตัวหนา** คือคำที่ต้องเน้นเสียง
- วงเล็บเหลี่ยมที่มีช่องว่าง คือส่วนที่ผู้สอนเติมเอง
```
ข้อสุดท้ายเขียนเป็นคำ ห้ามพิมพ์ `[ ]` ขึ้นต้นรายการ เพราะ Markdown หลายตัวจะแปลงเป็นช่องติ๊ก

### สรุป
- เปิดด้วย `สรุปสามข้อครับ`
- แต่ละข้อเป็นย่อหน้า ขึ้นต้นด้วยตัวหนา `**หนึ่ง**` `**สอง**` `**สาม**`
- ถ้าวัดเชิงพฤติกรรม ปิดด้วยย่อหน้า `และนี่คือสิ่งที่ผมจะดูในห้องปฏิบัติการครับ **//** ...`
  แล้วตามด้วย `**///**`

### Cliffhanger
- 2 ถึง 3 ย่อหน้า จบด้วยคำถามหรือความสงสัย
- ย่อหน้าสุดท้าย: `เจอกันในคลิปหน้า **[ชื่อคลิปถัดไป]** ครับ`

### ตารางภาพประกอบ
- ประโยคนำหนึ่งบรรทัด: `คลิปนี้มี N ช่วงภาพ โมชั่นหลัก N ชิ้น คือ [ชื่อ] กับ [ชื่อ]`
- ตาราง 3 คอลัมน์ `| ช่วงเวลา | เนื้อหาภาพ | ประเภท |`
- ช่วงเวลาเขียน `00:00 - 00:30` ต่อกันพอดีจนจบ
- คำในคอลัมน์ประเภทเลือกจากชุดนี้: ภาพแบ่งจอ / ข้อความ / กราฟิก / ถ่ายจริง / ถ่ายจริง + กราฟิก / การ์ดชุด / โมชั่นหลัก / โมชั่น / บันทึกหน้าจอ
- นับแถวให้ตรงกับ N ในประโยคนำ และนับโมชั่นหลักให้ตรงกับแถวที่ระบุ "โมชั่นหลัก"

### หมายเหตุผู้บรรยาย
- ย่อหน้าแรก: `**ลำดับการผลิต:** ผลิตหลังคลิป ... และก่อนคลิป ...`
- ย่อหน้าที่สอง (ถ้างานมอบหมายใช้เวลาหลายวัน): `**กำหนดปล่อย:** ...`
- ตามด้วย `###` สามหัวข้อ แต่ละหัวข้อเป็นรายการจุด
- "จุดเชื่อมกับคลิปอื่น" เขียนเป็น `คลิป X.Y (เรื่องที่เชื่อม)` คั่นด้วยจุลภาค
  และมีข้อ `ปูทางไปคลิป ...` เสมอ
- "จุดที่ต้องตรวจก่อนอัด" ต้องมีอย่างน้อย
  - ช่องที่ผู้สอนต้องเติม
  - ข้อเท็จจริงที่เปลี่ยนเร็ว
  - ตัวเลขที่เป็นเป้าหมาย ไม่ใช่สถิติ
  - การจับเวลาอ่านจริง
  - ตัวอย่างที่เป็นตัวอย่างสมมติ

## ตัวอย่างจริง (ย่อ) จากคลิป 4.1 วิชา Content Creator

ตัวอย่างนี้ใช้ดูน้ำเสียงและการวางสัญลักษณ์เท่านั้น เนื้อหาเป็นของวิชา Content Creator

2026-10-12 · [ชื่อผู้สอน]

## Cold Open และวางกรอบ (00:00 - 01:30)

**[00:00 - 00:40] Cold Open**

ลองนึกภาพคนสองคนนะครับ

คนแรก เปิดแอปขึ้นมาตอนเย็น นั่งจ้องหน้าจอเปล่า ๆ สิบนาที **//** แล้วพิมพ์ว่า "วันนี้โพสต์อะไรดีนะ" **//** สุดท้ายปิดแอป บอกตัวเองว่า "พรุ่งนี้ค่อยว่ากัน"

คนที่สอง เปิดโน้ตในมือถือ **//** เลื่อนดู เจอสี่สิบบรรทัด **//** เลือกมาหนึ่งบรรทัด แล้วลงมือทำเลย

**///**

คนที่สองไม่ได้เก่งกว่า ไม่ได้ไอเดียบรรเจิดกว่า **//** เขาแค่มี **ระบบ** ครับ

**[00:40 - 01:30] วางกรอบ**

เข้าสู่หัวข้อที่ 4 กันครับ

วันนี้เรามีสามเรื่อง หนึ่ง **Idea Capture System** ระบบจดไอเดียที่ไม่ปล่อยให้อะไรหลุด สอง **แหล่งไอเดียเจ็ดบ่อ** ที่ไอเดียไหลมาหาคุณได้เรื่อย ๆ และสาม **จังหวะทบทวนประจำสัปดาห์** ที่เปลี่ยนกองจดบันทึกให้เป็นของที่ใช้ได้จริง

**///**

## ส่วนที่ 1 ปัญหาไม่ใช่ไม่มีไอเดีย แต่คือไม่ได้จด (01:30 - 04:30)

**ข้อที่หนึ่ง จดไว้ที่เดียว** **//** ไม่ใช่โน้ตในมือถือบ้าง กระดาษทดบ้าง แชตหาเพื่อนบ้าง **//** แอปไหนไม่สำคัญ **ที่เดียวสำคัญ**

1. **อ่าน** ทั้งหมด
2. **ขีด** อันที่ยังรู้สึกน่าสนใจ
3. **รวม** อันที่ซ้ำกัน
4. **ย้าย** ตัวเด่นไปไว้ใน Idea Bank

## ส่วนที่ 2 แหล่งไอเดียเจ็ดบ่อ (04:30 - 11:30)

**บ่อที่หนึ่ง คอมเมนต์ของผู้ชม** **//** นี่คือบ่อที่ตรงที่สุด เพราะผู้ชมบอกคุณตรง ๆ ว่าเขาอยากรู้อะไร

แล้วถ้าคุณยังไม่มีผู้ชมเลยล่ะ **//** ไม่เป็นไรครับ ให้ไปอ่านคอมเมนต์ใต้คลิปของช่องในสายเดียวกัน

ตัวอย่างโน้ต "คนถามใต้คลิปช่องอื่นว่า ถ่ายอาหารด้วยมือถือให้น่ากินทำยังไง [บ่อ 1]"
