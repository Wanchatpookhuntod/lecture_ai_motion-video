ไฟล์นี้เป็นรายวิชาตัวอย่างสำหรับ workshop ใช้คู่กับ skill [lecture-clip-production](../../skills/lecture-clip-production/SKILL.md)
skill จะอ่านไฟล์นี้ก่อนทุกครั้ง แล้วผลิตสคริปต์คลิป quiz ใบงาน และคู่มือกิจกรรมให้ตรงกับวิชา

ช่องที่เขียนว่า `[รอผู้สอนกรอก]` คือข้อมูลที่ยังไม่มี เติมเองได้ หรือให้ skill เสนอค่าเริ่มต้นตอนพิมพ์ `เริ่มวิชาใหม่`

## คำอธิบายรายวิชา

ศึกษาหลักการออกแบบเกมและองค์ประกอบของเกม กฎการเล่น วงจรการเล่น กลไกเกม การออกแบบด่านและส่วนติดต่อผู้ใช้ การสร้างเกมต้นแบบด้วยกระดาษและด้วยโปรแกรมสำเร็จรูปสำหรับพัฒนาเกม การสร้างและจัดการทรัพยากรเกม กระบวนการทดสอบ ปรับปรุง และนำเสนอผลงานเกม

| กฎการเล่น วงจรการเล่น กลไกเกม | 1, 5 | CLO2 |
| การออกแบบด่านและส่วนติดต่อผู้ใช้ | 6, 10 | CLO2 |
| การสร้างเกมต้นแบบด้วยกระดาษ | **ยังไม่มีในแผน** | CLO2, CLO5 |
| การสร้างเกมต้นแบบด้วยโปรแกรมสำเร็จรูปสำหรับพัฒนาเกม | 2 ถึง 5, 8, 9, 12, 13 (Godot) | CLO4, CLO5 |

## ผลลัพธ์การเรียนรู้

### PLO ของหลักสูตร (คัดตามต้นฉบับ)

หลักสูตร วท.บ. วิทยาศาสตรบัณฑิต (เทคโนโลยีมัลติมีเดีย) (2569)

| PLO | คำอธิบาย |
|---|---|
| PLO1 | อธิบายแนวคิด ทฤษฎี ด้านศิลปะ การออกแบบ การสื่อสาร และเทคโนโลยี คอมพิวเตอร์ เพื่อใช้ในการพัฒนางานมัลติมีเดีย |
| PLO2 | ออกแบบและผลิตผลงานมัลติมีเดีย ให้สอดคล้องกับบริบทและการเปลี่ยนแปลงทาง เทคโนโลยี |
| PLO3 | ประยุกต์ใช้ความรู้และเทคโนโลยีด้านมัลติมีเดีย ตอบโจทย์ความต้องการของ ภาคอุตสาหกรรม เศรษฐกิจ สังคม และวัฒนธรรม |
| PLO4 | คิดริเริ่ม สร้างสรรค์ และนำเสนอผลงานมัลติมีเดียอย่างเป็นระบบ โดยคำนึงถึง แนวคิดและกระบวนการที่มีประสิทธิภาพ |
| PLO5 | ปฏิบัติตนตามหลักคุณธรรมและจริยธรรมทางวิชาชีพ แสดงภาวะผู้นำ สามารถ ทำงานเป็นทีม และแสวงหาความรู้ตลอดชีวิต |

### CLO

เมื่อจบรายวิชา นักศึกษาควรสามารถ

| CLO | ข้อความ | ระดับ Bloom |
|---|---|---|
| CLO1 | วิเคราะห์หลักการ Game Design และองค์ประกอบของเกมได้ | วิเคราะห์ (Analyze) |
| CLO2 | ออกแบบ Gameplay Loop, Mechanics, Level และ UI/UX ของเกมได้ | สร้างสรรค์ (Create) |
| CLO3 | สร้างและจัดการ Game Asset ได้แก่ Graphic, Animation, UI และ Audio ได้ | ประยุกต์ใช้ (Apply) |
| CLO4 | ใช้ Godot สร้างระบบเกมโดยใช้ Node, Scene, Signal และ GDScript พื้นฐานได้ | ประยุกต์ใช้ (Apply) |
| CLO5 | พัฒนาเกมต้นแบบที่สามารถเล่นได้จริง ตามแผนการผลิตและกำหนดส่งที่วางไว้ได้ | สร้างสรรค์ (Create) |
| CLO6 | ทดสอบเกมกับผู้เล่น ปรับปรุงเกมจากผลการทดสอบ และนำเสนอผลงานเกมในรูปแบบ Portfolio ได้ | ประเมินค่า (Evaluate) |

ระดับ Bloom ใช้สำหรับออกแบบการประเมิน

### ตาราง CLO กับ PLO (ข้อเสนอ รอผู้สอนยืนยัน)

● = รับผิดชอบหลัก ○ = รับผิดชอบรอง

| CLO | PLO1 | PLO2 | PLO3 | PLO4 | PLO5 |
|---|:-:|:-:|:-:|:-:|:-:|
| CLO1 วิเคราะห์หลักการ Game Design | ● | | | | |
| CLO2 ออกแบบ Gameplay, Level, UI/UX | | ● | | ○ | |
| CLO3 สร้างและจัดการ Game Asset | | ● | | | |
| CLO4 ใช้ Godot สร้างระบบเกม | | ○ | ● | | |
| CLO5 พัฒนาเกมต้นแบบ | | ○ | | ● | ○ |
| CLO6 ทดสอบ ปรับปรุง นำเสนอ Portfolio | | | | ● | ○ |

เหตุผลโดยย่อ
- **PLO1:** CLO1 อธิบายหลักการและองค์ประกอบของเกม ตรงกับการอธิบายแนวคิดด้านการออกแบบ
- **PLO2:** CLO2 และ CLO3 คือการออกแบบและผลิตชิ้นงานเกม
- **PLO3:** CLO4 ประยุกต์ใช้เทคโนโลยี (Godot) สร้างระบบเกมจริง
- **PLO4:** CLO5 และ CLO6 คือการสร้างสรรค์เกมอย่างเป็นระบบและนำเสนอผลงาน
- **PLO5:** มาจากการทำงานเป็นทีมในช่วงผลิตเกม (สัปดาห์ 13 ถึง 16) ถ้าวิชาให้ทำเกมเดี่ยว ควรตัด PLO5 ออก

## กฎเฉพาะวิชา

- ตัวอย่างโค้ดใช้ GDScript ของ Godot 4 ระบุเวอร์ชัน Godot ที่ใช้จริงใน "จุดที่ต้องตรวจก่อนอัด"
- ภาพบนจอใช้ม็อกอัปหรือหน้าจอ Godot ของผู้สอนเอง ห้ามใช้ภาพเกมที่มีลิขสิทธิ์
- Asset ตัวอย่างต้องเป็นของผู้สอนเอง หรือเป็นสัญญาอนุญาตเปิด (เช่น CC0) และระบุแหล่งที่มา

## จุดที่ยังรอผู้สอนตัดสินใจ

1. จะเพิ่มกิจกรรมเกมต้นแบบด้วยกระดาษในสัปดาห์ไหน (ข้อเสนอ: workshop สัปดาห์ 1 ทำ Game Concept เป็นเกมกระดาษ และเล่นทดสอบในห้อง)
2. ตาราง CLO กับ PLO (ตอนนี้เป็นข้อเสนอ) และ PLO ที่หลักสูตรมอบให้วิชานี้รับผิดชอบ
3. CLO ของแต่ละสัปดาห์ในแผนการเรียน (ตอนนี้เป็นข้อเสนอ)
4. เกณฑ์ประเมินและสัดส่วนคะแนน
5. ตัวอย่างต่อเนื่องตลอดเทอม

## ลองใช้ใน workshop

1. คัดลอกโฟลเดอร์นี้ไปเป็นโฟลเดอร์งาน แล้วเปิดใน Claude Code
2. พิมพ์ `เริ่มวิชาใหม่` เพื่อให้ skill ตรวจการ์ดและเสนอโครงคลิปและการประเมิน
3. พิมพ์ `script 3.1` เพื่อเขียนสคริปต์คลิปแรกของสัปดาห์ 3 (Player Controller)
4. พิมพ์ `ตรวจ script 3.1` แล้วตามด้วย `ดำเนินการ` เพื่อแก้ตามผลตรวจ
5. พิมพ์ `ชุดผลิต สัปดาห์ 3` เพื่อทำ quiz ใบงาน และคู่มือกิจกรรม
6. พิมพ์ `word` เพื่อส่งออกเป็นไฟล์ .docx
